# Chapter 3
## Tech Stack

This chapter outlines the technologies, frameworks, and tools used to build the BRTA 2.0 system. The chosen tech stack ensures scalability, security, and a seamless user experience for all stakeholders.

### 3.1 Frontend
- **Framework:** React.js for building dynamic, responsive user interfaces.
- **UI Library:** Tailwind CSS for consistent and modern design.
- **Routing:** React Router DOM for client-side navigation.
- **Animation:** Framer Motion and Lottie for interactive UI elements.
- **Charting:** Recharts for analytics and reporting dashboards.

### 3.2 Backend
- **Runtime:** Node.js for scalable server-side logic.
- **Framework:** Express.js for RESTful API development.
- **Database:** Supabase (PostgreSQL) for secure, scalable data storage and real-time updates.
- **File Storage:** Supabase Storage for document uploads and digital license storage.

### 3.3 AI & Chatbot
- **AI Service:** Gemini 2.5 Flash Lite for fast, cost-effective chatbot responses.
- **Session Management:** In-memory storage (Map) for active chat sessions.
- **Language Support:** API integration for English and Bangla responses.

### 3.4 Payment Integration
- **Gateway:** SSLCommerz for secure online payments.

### 3.5 Notifications
- **Email:** Nodemailer for transactional and notification emails.
- **In-app:** Custom notification system using frontend state and backend event triggers.

### 3.6 Security
- **Encryption:** TLS/SSL for data in transit, AES for data at rest.
- **Validation:** Input validation and sanitization at both frontend and backend.
- **Compliance:** Adherence to Bangladesh’s data protection laws and regular security audits.

### 3.7 Deployment
- **Hosting:** Vercel or custom VPS for frontend; Supabase and Node.js server for backend.
